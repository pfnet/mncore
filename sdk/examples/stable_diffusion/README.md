# Licenses for the model, part of the source code, and the dataset used for training

## About the model

The model used for this training and evaluation workflow is [CompVis/stable-diffusion-v1-4](https://huggingface.co/CompVis/stable-diffusion-v1-4), and its license is [creativeml-openrail-m](https://huggingface.co/spaces/CompVis/stable-diffusion-license). This example includes processing to download the relevant model file.

## Licenses for functions and modules referenced in the source code

This source code includes processing and functions created with reference to items in [huggingface / diffusers](https://github.com/huggingface/diffusers/tree/main), which is distributed under the [Apache License, Version 2.0](https://github.com/huggingface/diffusers/blob/main/LICENSE). The referenced parts are as follows:

- [train_text_to_image.py](https://github.com/huggingface/diffusers/blob/main/examples/text_to_image/train_text_to_image.py)
- The full set of dataset object creation steps used when creating the dataloader
- The processing inside the Stable Diffusion training loop

## About the dataset

This example uses a modified version of [Caltech 256](https://data.caltech.edu/records/nyy15-4j048), which is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode). The specific modifications are listed below. This deliverable also includes a script to download the dataset and a script to apply the modifications described below.

- Renaming the directories generated by extracting the downloaded tar file, where each directory is named after an object category, and renaming the image files contained in each directory
- Creating and placing a file named `metadata.csv` in each directory for each object category
