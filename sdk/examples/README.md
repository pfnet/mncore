# MLSDK Examples

This directory contains example programs for MLSDK, included in the MN-Core SDK.
These examples are identical to those bundled in the distributed MN-Core SDK Docker image.

* **Version Compatibility**:
The examples correspond to the latest version of the MN-Core SDK.
To reference examples for previous versions, please select the appropriate tag from the **Tags** menu.

----

## Quick Start

### 1. Prerequisites

Refer to [MN-Core Developer Central](https://dev.mn-core.com/) to set up an environment with the MN-Core SDK installed.

### 2. Documentation

For detailed information on each example, please refer to the following:

* [docs/en](https://dev.mn-core.com/sdk/0.4/MLSDK/docs/en/)
* [docs/ja](https://dev.mn-core.com/sdk/0.4/MLSDK/docs/ja/)

### 3. Running Examples

Once your environment is ready, execute the scripts as follows:

```bash
# For Python scripts
$ ./exec_with_env.sh python3 <example-name>.py

# For shell scripts
$ ./<example-name>.sh
```
